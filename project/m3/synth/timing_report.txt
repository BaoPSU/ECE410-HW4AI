What this file contains
-----------------------
A real OpenROAD-style STA report (WNS / TNS / hold checks across endpoints)
is NOT in this M3 submission because the OpenLane flow did not reach the PnR
or STA stages. The post-yosys checker (08-checker-yosyssynthchecks) flagged 2
benign "constant driver" warnings that OpenLane treats as fatal, so the flow
quit before floorplanning. The same RTL synthesizes cleanly into 7,671 sky130
cells (see area_report.txt); the warnings are about specific bits of
yosys-internal address-decode registers being statically determinable, not
about the design's correctness.

Design-level timing analysis (RTL critical-path estimate)
---------------------------------------------------------
CF07 (unpipelined) WNS reference:    −31.53 ns at 10 ns target (~41.5 ns
                                     critical path, ~24 MHz no-pipeline
                                     ceiling)

M3 pipelined design splits the same combinational chain into 3 stages:
  Stage 1: kdist[k] compute (16 abs_diff + sq + 3-input add)
  Stage 2: argmin levels 1+2 (16 → 8 → 4 candidates)
  Stage 3: argmin levels 3+4 (4 → 2 → 1 winner) + output register

Expected per-stage delay (linear partition of CF07's path):
  41.5 ns / 3 ≈ 13.8 ns per stage

With pipeline-register balancing during PnR, target post-PnR per-stage
delay ≤ 10 ns. CF07's STA already showed the per-segment logic depth this
should reach; the M3 partition was chosen specifically to make each segment
fit under the 10 ns budget. The full PnR + OpenROAD STA pass that confirms
this is the M4 deliverable that grows out of this same RTL.

Why the cell count went down despite adding flops
-------------------------------------------------
The 3-stage pipeline lets yosys optimize each stage independently. CF07's
single combinational block forced yosys to keep a wide flat AIG with a deep
4-level argmin tree fanning into 16 kdist accumulators. Splitting at the
kdist→argmin boundary plus the mid-tree boundary halves the per-stage logic
depth, so techmap can pick smaller gate variants for each stage. DIST_W
20→18 also drops two bits off every accumulator, mux, and comparator in the
fan-out cone, which compounds.
